## 1. 统一 V1.1
严格按同目录 `stm32-serial-v11.md`：version=02，四类固定长度30/13/8/8，MAX_PAYLOAD=64 仅缓冲容量，MCU 采样时间和当前会话，三个新状态位。修订黄金字节、Python 编码/解析与模拟器。保持 V1 历史文档/测试证据可查；当前实际入口明确只支持 V1.1，不要求运行时兼容两版，不自动降级。若原测试脚本名带 v1，更新名称/文档并说明，避免测试覆盖歧义。统一非零会话，优先处理会话失配再校验 seq，板复位仍有遥测必须恢复握手。未握手/无授权可显示诊断遥测但不能喂控制。合法 STOP 可被未授权/故障状态接收并 ACK；初次等待与运行超时分离，不盲目增大保护时间。正式串口和 GUI 路线都必须防止异常恢复后旧 running 自动触发 ENABLE。结合现有 GUI resume 门尽量复用简单逻辑。对 STOP/0 空闲重启是否保留本地物理授权，暂按保守规则，硬件组确认后再调整，不新增假使能或远程解锁。

## 2. 状态和实验记录
- 修正 unarmed/not_calibrated/真实 fault 与通信异常的本地诊断；不需要增加 UDP 字段。对旧正式 VR 的 stop/reason 行为做兼容核查。无 ANGLE_VALID/角度陈旧不得正常控制，即使遥测序号增长。对速度/力无效标记 null/未提供；为不依赖速度的 legacy+symmetric 保留必要内部占位，不将其冒充实测速度、功率或方向依据。
- 复用 GUI 已有实际完整写出/ACK/MCU 回报观测，加入会话及 MCU 采样时刻、ACK 进度超时、序号/CRC 等必要诊断。仅 STOP 默认后端门保持；首次板卡功率隔离，无人体。ACK 进度容许正常时序差，先用 200 ms 窗口测量，确认 ACK 属于当前会话且对应近期完整写出的命令；不把未写出/仅入队或重复 ACK 当成功。串口写入有界，避免旧非零命令堵塞或被误报已发。发生故障/超时撤销正常输出，尽可能发 STOP，再由 MCU 本地看门狗独立处理；不声称软件 STOP 等于机械停止。
- 增加显式实验日志选项：尽可能逐条保存有效/诊断遥测与实际完整写出命令、PC monotonic 时间、MCU 采样时间、线序号、会话、原始状态位、ACK、目标及传感器有效位。GUI 5–10 Hz 刷新即可，完整记录与 GUI 渲染分开，有界日志缓冲；丢记录需有计数与提示。记录所有无效/缺失的实际含义，不把 MCU 回报目标称为实测力矩。
- 保持初始 115200（USART）/100 Hz 遥测/50 Hz 命令/200 ms 看门狗建议值。说明非阻塞中断/DMA 的选择由固件实现，实测周期/ACK 进度再决定参数，不为了提高带宽强制更高波特率。

## 3. 直接给 STM32 同学的 C 参考代码
建议 `firmware_reference/stm32_v11/aw_protocol.h` 与 `aw_protocol.c`，加小型 PC 编译测试及中文 README。实现固定端序、CRC16、严格长度、分包粘包、错误帧恢复、组帧超时、uint16/uint32 回绕、黄金报文验证；无第三方依赖、无动态内存、不直接 memcpy 带 padding 结构体、不含具体 STM32 引脚/电气参数。附很短的会话/ACK/看门狗接入示例或可测试的纯逻辑模块，明确哪些需板端应用调用。安全许可、采集有效性、实际输出及独立保护由实际固件/电气组接入确认，不提供未经验证的 PWM 电流扫值程序。C 语言参考在本机用可用编译器测试；如无 F405 工具链，仅报告 host 编译测试，不说已在 STM32 烧录。Python 与 C 从同一协议黄金向量互测，补充复位场景。

## 4. 最小验收
- Python 编解码黄金字节、旧版本拒绝、零 session、错误长度/CRC、分包粘包、序号自然回绕和 MCU 时间自然回绕。
- 同一物理 COM 上 MCU 单独复位（旧遥测序号取 32769..65535 与低序号），仍发送 session=0 的诊断遥测，PC 不永久卡住；匹配会话恢复后先 STOP/ACK，再明确操作继续。错误会话/迟到帧、采样时间停滞而遥测 seq 增长、ANGLE_VALID 清零、速度/力无效、ACK 卡住而遥测仍来、串口发送中断、正常 STOP 空闲重启、真实故障和命令超时状态。仅 STOP GUI 即使收到外部 running 也不产生 ENABLE。
- Windows 实际 GUI + 已有虚拟 COM 对运行：刷新端口/连接，诊断模式无需授权；明确选择模拟比赛，选择至少一个非 demo 人物和策略，开始/暂停/继续/结束、复位恢复及日志 ZIP。仅软件虚拟端使用 --demo-arm。核对新版真实字节和完整记录，保留简洁截图。更新操作指南与联调记录，运行相关 Python 及 C 测试；不要求重复 Unity 大规模回归或修复无关 MuJoCo DLL。
- PC 重新握手/恢复通信不能替代实际硬件授权；真实 STM32、控制器、编码器与制动器尚未到位时，只报告模拟验证。
