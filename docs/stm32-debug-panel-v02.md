# STM32 联调助手 V0.2

这个工具用于首次接板排错，也可以在 Windows 虚拟 COM 对上用模拟 STM32 复验。串口使用 [V1.1](stm32-serial-v11.md)，模拟 VR 使用原有 UDP V0.1。默认进入 **串口检查 · 仅 STOP**。

## 启动与接板

解压交接包后双击 `start-stm32-debug.cmd`。脚本会显示它实际使用的 Python，检查 Python 3.10+、Tkinter 和 pyserial。缺依赖时，按窗口提示在选中的 Python 上修复。已有虚拟环境时，安装命令如下。

```powershell
.\.venv\Scripts\python.exe -m pip install pyserial
.\start-stm32-debug.cmd
```

首次接实体板时由下位机、电气组确认制动器励磁功率已物理隔离，设备旁无人接触。刷新并选实际 COM。USART 默认 115200、8N1。USB CDC 使用相同帧格式。

要在虚拟 COM 对上复现，另一窗口先运行模拟器。把 COM2 和面板中选择的 COM1 换成你电脑上的一对端口。

```powershell
.\.venv\Scripts\python.exe -m sim.mock_stm32_serial --port COM2
```

只查通信即可使用上面的命令。需要模拟比赛时，重新启动模拟端并加 `--demo-arm`，该参数仅用于软件模拟器。

## 按顺序看状态

| 看到的状态 | 可以先查什么 |
| --- | --- |
| COM 已打开，RX 为 0 | 设备是否在发数据、COM 配对、USB 或串口接线。PC 端 TX 增长只表示本机串口 API 接受了字节 |
| RX 增长，合法帧仍为 0 | 波特率、线上版本 `02`、帧头、定长字段和 CRC；复制收发 Hex 给同学 |
| 诊断遥测有数据，握手仍等待 | 板端是否收到了 OPEN，并回送编号一致的 SESSION_ACK |
| 会话匹配，STOP 等待确认 | 检查板端命令接收、匹配会话遥测、`ACK_VALID` 和回报序号 |
| STOP 已接受，回报目标非零 | 当前会话仍只发送 STOP。检查板端处理 STOP 后的目标、状态更新和回报字段 |
| STOP 已确认，未获本地许可 | 串口可以正常验收。比赛还需有效角度、持续遥测和本地授权 |

**串口详情**显示本次 COM 打开以来的累计统计。同端口重建会话时保留，重新打开 COM 后清零。RX 是实际读到的字节。TX 是串口 API 返回已接受的字节，另有完整写出帧数。合法帧通过帧头、长度、CRC 和载荷解码。会话遥测通过会话和新序号校验。有效角度要求匹配会话、采样时间推进且本次角度有效。同步跳过统计搜索下一处 `A5 5A` 时跳过的字节，包括坏帧之后重新搜索时跳过的内容。坏头、CRC 和组帧超时另计，不能直接相加当成错帧数。

**收发 Hex** 页的预览为最近各 32 字节的原始尾部，可能从帧中间开始。复制后可发给同学。它只在面板实时显示，不写入导出的诊断快照。`—` 表示未提供或无当前数据。状态位有文字和 0/1，过期数据不表示“已解除故障”。其中 `FORCE_VALID=0` 时测力缺失，命令目标与 MCU 回报也分别显示，单位均为 N·m 或 mN·m。MCU 回报零目标不等于实测零力矩或机械停止。

## 模拟比赛和趋势

1. 断开连接后选择 **模拟 VR 比赛**、人物和策略，重新连接。按钮提示就绪后手动开始。换策略时重连。人物参数为演示值。
2. **控制区域**按实际生效配置显示自由区和阻力区。默认 `q ≤ 0.25 rad` 为自由区，机械负角越过约 −14.3° 后进入阻力区。暂停、等待、未授权、无有效角度等状态优先提示。进入阻力区后，模型和保护仍可能给出零目标。
3. 点 **角度 / 阻力趋势** 看最近约 10 秒。左图是机械角度、零位和自由区边界。右图分别是 PC 计算目标、完整写出目标及 MCU 回报目标。它使用约 5 Hz 面板快照，缺测或换会话会断开，不应用来判断毫秒级响应。
4. 点 **暂停** 或在面板聚焦时按 **F8**。默认离开窗口焦点也会暂停。**窗口置顶**可单独开关。
5. 只在软件仿真或励磁功率已物理隔离时，可以在断开状态勾选 **后台调试** 并确认。启用后切到别的窗口可以继续模拟比赛。最小化、关闭、面板卡顿、后端退出、许可或通信异常仍会撤销正常阻力。恢复须手动继续。带功率联调使用默认设置及实际设备的独立保护。

## 保存和离线分析

连接前勾选 **记录逐帧实验日志**。实验后先断开，再点 **保存本轮日志…**，以便保存最终丢记录统计。ZIP 包含面板事件、PC 低频快照、逐条遥测与完整写出命令。发给同学时带上固件版本、端口和复现步骤。

```powershell
.\.venv\Scripts\python.exe -m tools.plot_experiment ".\本轮日志.zip" --out-dir ".\analysis"
```

工具也接受 `experiment.jsonl`，输出 `experiment.csv` 和 `summary.txt`。ZIP 里有 PC 快照时另写 `pc_snapshots.csv`。PC 单调时间和 MCU 采样时间独立分析。空读数保留为空，统计不能用来计算单程传输延迟。
