## 2. 第一小步：补齐 narrow 的推进与回推证据

优先 person_02 + balanced，先不改任何控制律。

### A. 可推进性

冻结原 V0.5-A 序列与 20 ms 步进，从同一软件零位开始，复用已有 0.045/0.065/0.090 N·m 三档；增加少量较大的幅值，例如 0.12 和 0.18 N·m，并追加一个固定的较长下压段（例如把原 0.66 s 延长为 1.32 s）。所有候选使用相同输入，完整记录预先选定的试验，不只挑有利结果。先以 legacy/narrow 为主，start-resistance 仅作必要对照。

记录峰值 q、首跨 25°、连续超过该角线的最长时间、是否达到 0.35 s 判定保持时间、是否触模拟限位、目标幅值、耗能估计与疲劳。注明离线角度保持只是一项判据模拟，不等于正式 VR 比赛结算。不要为使 narrow 获胜调整人物上限、惯量、阻尼、限位或判定线。如果较强或较长的输入仍不可推进，直接说明限制。

### B. 同起点回推（解决 V0.5-A 比较不公平的问题）

以前同序列回推时各方案从不同 q 开始，因此不能直接用退让位移评价谁更容易回推。本轮用现有 SimulatedDevice 的测试初始化能力，从相同 q（建议 0.10、0.25、0.40 rad，初始速度为 0）及明确的控制状态开始。对 legacy 与 narrow 施加相同、足够持续时间的回推输入（至少一组 1–3 s 的有限软件力矩），再松手。可增加一次短时正反往返。
- 若预先用固定遥测建立阻力，所有候选采用相同预处理时间与状态，分别记录回推开始的目标、疲劳和速度；不能假装各曲线的疲劳状态天然相等。比较 narrow 内的新旧方向策略时则保持相同预处理、初始疲劳和已建立目标。
- 初始角度只在测试 harness 初始化，不在正常比赛中偷偷重置位置，不增加实机 reset 命令。
- 记录退让量、到 q=0.05/0 的时间（未到注明）、正负向峰值速度、回推期间最大阻力和耗能。另用固定 q、给定正/负速度的探针隔离方向变量。
- 软件施力的符号可用于实验标注，但不能作为 PC 策略的隐藏输入。PC 当前只有角度和速度；**真实用户松手、继续用力或意图后退不能仅凭速度准确判断**。区分“模拟用户输入已归零”与“机械实际已经停止运动”。

## 3. 第二小步：可选的方向相关退让候选

如果第一步证实较早的制动确实在回推时产生明显阻碍，则增加一个简单、可关闭的方向调制实验；若影响不明显，先仅交付第一步的数据与结论，不为凑功能增加复杂模型。

现有控制始终使用相同的无符号目标幅值，再由 passive_torque 按当前速度决定制动方向。因此推进、回推都阻碍运动。对 narrow 的候选目标增加一个方向系数，只在朝 q 减小方向运动时减小阻力：

```text
qdot = forward_sign * omega
return_fraction = clamp(-qdot / transition_speed, 0, 1)
direction_scale = 1 - (1 - return_ratio) * return_fraction
M_requested = M_base * strategy_scale * direction_scale
# 后续沿用 V0.4/V0.5-A 疲劳负载、剩余能力和发力建立
```

- 原方案 direction_scale=1（symmetric）。首个退让候选可用 return_ratio=0.5、transition_speed=0.05 rad/s（演示值，与已有速度过渡尺度一致）。qdot≥0 保持原请求；qdot<0 时随反向速度连续减小，达到过渡速度后为原请求的一半。若采用其他简单平滑函数，说明理由。先不扫大量参数。
- 方向系数乘在原策略请求上、再进入原疲劳和缓升；方向调制后的负载代理仍是软件设定而非肌电。恢复推进时使用既有缓升，不积累旧制动目标。零速附近不因噪声出现阶跃或快速切换；必要时做少量边界/速度抖动探针。
- 这个候选只是“检测到反向运动时减少阻碍”，不是识别用户意图，更不是虚拟对手主动推进。制动方向继续由已有 passive_torque 决定，M≥0、实际模拟功率≤0。所有暂停、fault、过期、waiting、finished、重连、角色锁定和看门狗优先级不变。
- 可用 TCP 模拟 CLI `--return-mode symmetric|relief`（名称可调整）或独立实验脚本；默认 symmetric。demo 绕过该候选。若接入 BridgeState，新增少量本地诊断字段（模式、qdot、direction_scale），不扩展 UDP 或串口帧；real.run 不启用候选。
- 用同一窄自由区、同一初态、同一施力、相同策略的回推试验比较 symmetric 与 relief，先检查固定角度正向不变、反向减阻、停止规则和能量；再检查实际闭环推进、回推及往返。不要要求所有回合获胜，也不要把退让更快直接等同于更真实。
