# 机械参考资料（建模前必读）

- [简化布局草图](armwrestling_layout.svg)：说明用户、肘垫、竖直握把、双杆摆臂、转轴及后部制动机构的相对关系，属于**示意图**而非最终 CAD 尺寸图。
- 原始机械设计图：由用户提供的带标注的三维参考图。**本次尚未上传 PNG 原件**，请先获取原图后再对主轴方向、双杆连接、运动轨迹做最终判断。

## 建模注意

1. 用户将肘部放在肘垫上，手握摆臂前端竖直握把；对手在 VR 场景中体现，不需要额外制作真人或机器人对手实体。
2. 原始图显示双杆摆臂由固定支座承托，**主轴可能是水平轴**；当前 MuJoCo V0.1 中使用的竖直轴未必符合实际。
3. 修改为水平轴时，摆臂重力会产生额外力矩，不能用主动补偿假装真实磁粉制动器具有驱动能力。
4. 本示意图不能代替机械组的最终 CAD，轴线方向、相对高度、左右手布局与空间尺寸以机械组确认的设计为准。
5. 在尚未看到原始图时，不要根据这张简化草图推断不存在的尺寸与配合关系。
