## 2. 研究问题

原控制令 q=-theta（用户获胜方向为 q>0），M_old(q)=min(Mmax,K*max(0,q-0.25))。即 q<=0.25 rad（14.3°）无额外制动。当前 VR 演示的视觉胜负角为 ±30°、映射系数 1.2，对应机械角线约 ±25°（q_win=0.436332 rad）。从零位到获胜角线，约 57% 行程尚无额外制动。策略只是缩放原静态目标，因此不能改变原来的阻力起始区域。

真实磁粉制动器是被动执行器，不能主动压回用户。现有模拟的 signed torque 在速度为 0 时为 0，不代表真实制动器的静态抗转矩。本轮不引入主动回零/对手推进/静摩擦模型；软件改善不能冒充人体手感验证。

## 3. 三个实验候选（只改变角度→基础目标）

优先以 person_02 + balanced 隔离问题。保留旧曲线 legacy，新增两个易懂的实验曲线。**公平比较应尽量在同一获胜角线保持同一静态目标，而不是仅减少自由区后仍使用原斜率，导致整体阻力无意变大。**

设 W=25°（弧度），T=M_old(W)，以下 W 只用于当前演示对照，非物理安全限位。

- A / legacy：完全不变，M=M_old(q)。
- B / narrow：自由区缩小为 0.05 rad（约 2.9°）。q<=0.05 时 M=0；0.05<q<W 时 M=T*(q-0.05)/(W-0.05)；q>=W 时沿用 M_old(q)。保持连续、在 W 与后续行程同旧曲线。
- C / start-resistance：在零位附近允许少量阻力目标。初始示例 M0=0.15*T（演示比例）。0<=q<W 时 M=M0+(T-M0)*q/W；-0.05<q<0 时 M=M0*(q+0.05)/0.05，向对手获胜侧逐渐退到 0；q<=-0.05 时 M=0；q>=W 沿用 M_old(q)。该小负角过渡只为避免零位阶跃，并不模拟主动进攻；如采用更简单等效连续方案，记录定义。
- M 始终在 [0,Mmax] 内；保留 V0.4 策略乘法、疲劳负载和缓升模块，使后续目标不超当前候选基础幅值。注意 B/C 在部分角度会比旧曲线有更大阻力，这正是本轮实验变量，而非硬件许可。
- 默认永远为 legacy；demo 在全部实验选项下均严格绕过实验曲线，复现原控制。保留原控制纯函数及人物参数。新函数尽量纯、易测试。若需要 CLI，建议仅软件 TCP 模拟入口提供 `--resistance-profile legacy|narrow|start-resistance`（名称可依实现简化）；不为 `real.run` 开放实验选项，不改变实机路径默认输出、不修改固件、串口 V1 或 UDP V0.1。也可先用隔离的对照脚本实现，避免不必要的公共架构。
- 本轮优先 balanced，冻结 V0.4 的三策略定义。不要同时调整防守策略的阈值、反应时间常数或节奏周期；若候选进入共用状态层，明确现有防守比例仍使用原参考边界，其他策略兼容性只作回归，后续单独评估。

## 4. 软件验证和选择依据

### A. 固定输入/曲线

1. 先画/输出三个候选的静态角度扫描（q 从负角到正角限位），标记零位、旧/新自由边界、25° 阈值、人物上限。三个候选在 W 及其后应精确相等或在明确浮点容差内一致。
2. 对 person_02 使用相同的有效时间、输入角度及速度，比较零位（q=0）、小角、旧边界、接近阈值及回推。记录基础目标、策略请求、最终下发、疲劳、模拟有符号制动与功率。特别区分静止时的目标幅值与速度规则下的实际模拟制动力矩；不宣称 C 可以静止主动发力。
3. 保持 A/legacy 的 V0.4 精确回归，测试 B/C 连续、单调推进段、有界、无非有限值、demo 旁路、全部 STOP/0 与超时保护。实际时间/角色锁定/疲劳重置行为保持原样。

### B. 相同用户施力的闭环

沿用 P3.0 SimulatedDevice 和固定 20 ms 步长。从同一零位、新一局和 person_02 + balanced 开始，复用 V0.4 的完整 0.065 N·m 序列；再预先确定少量较小及较大的有限软件力矩幅值（例如 0.045、0.065、0.09 N·m），对所有候选采用相同输入，记录全部结果，不能只挑有利工况。必要时追加一个低速推进/释放/回推序列，不改机械惯量、阻尼、限位、人物能力和胜负阈值。

记录目标阻力初次建立位置、峰值推进、达到 25° 的时刻（未达则标记）、触限位与否、最大下发、制动消耗能量/功率、疲劳、回推轨迹。可直接记录 CSV 加 1 张对照曲线图（时间曲线与静态曲线）。比较时注明离散步长/实际角速度，首次跨线不等于实际比赛胜负。

不预设 B 或 C 必须获胜，也不以“阻力越大越好”作为选择标准。候选主要评估：是否让起步阶段有阻力、是否仍可推进、是否避免突然顶死，以及回推时是否出现不合理的阻碍。在实际设备完成独立保护及标定前，仅能选出更值得继续仿真/台架验证的候选，不能确定人体最佳体验。

### C. 正式 VR 最小复验

如 Windows 本机正式场景可用，用相同人物、balanced 和两个/三个候选进行代表性实际 Editor 联调（非旧长方体 Demo）。保持 P3.0 UDP、角色、准备/倒计时 STOP/0、角度映射、暂停、结束、断联与复位。结合模拟施力操作与 PC 日志观察开赛后近零位的响应，不要求调整正式场景或强行让每种方案完赛。如果现有 Unity 被其他任务使用，A/B 可独立交付，注明 C 未执行。
