## 报文差异与数值来源

如不匹配，记录发送方/接收方、期望与实际报文（JSON 或十六进制）、时间、seq/session_id、CRC/单位差异。协议调整须双方确认，不能各自改字段。没有发现差异时注明本次覆盖范围。

力矩记录分别填写静态 M_base、疲劳后 M_eligible、PC 下发 M_output、MCU 回报目标和台架实测力矩；无传感器或未标定时，实测项写“未测”。传感器力只有 FORCE_VALID 有效才可引用，并写明单位及力臂。
