# 首次接板时的确认事项

| 需要确认 | 由谁提供 | 本次交接可先做什么 |
| --- | --- | --- |
| 使用 USB CDC 还是 USART；接口、电平、接线、COM 信息及固件版本 | 下位机组 | 先用 C 黄金帧测试，接板后确认实际端口 |
| 主轴角度传感器型号、安装方向、零位、量程和采样周期 | 下位机、机械组 | 映射到 mrad；初始化或数据过期时清 `ANGLE_VALID`。角度、采样时刻与有效位在同一快照发布 |
| 速度计算、时间基准；传感器测量 N 还是 N·m、去皮/标定方法 | 下位机、机械组 | 未实现的通道填零并清 `VEL_VALID` / `FORCE_VALID`。力矩传感器的读数另行约定单位和字段 |
| 本地授权、急停、故障复位、机械限位、看门狗及断线失效行为 | 下位机、电气组 | 先物理隔离励磁只测会话、STOP/ACK 和遥测。通信恢复后由独立保护和实际本地流程决定何时重新授权 |
| 励磁到主轴目标的映射、测力矩基准、有效上限、变化限值及响应时间 | 电气、机械组 | 遥测可报告限幅后的目标。完成独立保护确认，再安排无人台架标定 |

板端接入点见 [C 参考说明](../../firmware_reference/stm32_v11/README.md)。对接记录请附固件版本、设备与线缆、测试时间、是否隔离励磁、所用数据采样条件和 PC 导出的日志。
